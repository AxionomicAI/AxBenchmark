Its **BD-001–006** cover decision profiles, scoped context detail, backend-aware judging, readiness/navigation, offline evidence and resource disclosure. This companion is a reading/implementation map; it does not add a second backlog or claim runtime completeness.

Read-only prototype verification on 2026-10-03 confirmed the overall inventory of **194 named boards, 233 size variants and 514 focus renders**. Rendered references include HarnessLive/Limited/ContextOff; ContextDetail (wide and compact), History/Deferred/Failed/Reset/Imported/Retained; DecisionEngines (wide and compact), Empty/Local/Missing/Edit/Test/Tested; SetupNoEngine and SetupGradingTextOnly. Most variant boards are wide only. List loading/error, full compact/resize transitions, current exact DTO changes and domain/route/Human integration remain pending in their BD items. Static pictures and focus frames do not prove API behavior or native support.

Keep `ContextTarget` and `AnalysisSelection` through each entry/return and paging transition. Use `measurements.context.sessions/snapshot/history/segments/analysis`; explicit reclassification alone uses `measurements.context.reclassify` with frozen destination/profile/pack/policy/budget/source/idempotency. Registered context events on `measurements` use M15 full EventCursor/revision/resync. A late response from another trial, agent, window, snapshot or analysis cutoff cannot replace the current selection.

Show count method/fidelity/basis, native versus predicted classification/confidence and actual membership separately. Preserve known native total with unknown partition, not_exposed hidden reasoning, unclassified/gaps, native disagreements and compaction/reset. Never turn unknown into zero, infer hidden content, sum stream/billing history as current occupancy, pool nested windows or force category shares to 100%.

No configured compatible READY and explicitly selected decision profile disables only new classification/reclassification or decision grading for the affected role. Keep configuration remedies, passive/native evidence, ordinary statistics, eligible harness/Human judging and saved/offline analysis available. Saving a profile does not select a role. Deferred/failed/partial observer work does not block report/export after ordinary capture/retention and original-review settlement; durability failures and pending original Human cases do. A report/ZIP pins each capture's actual selected analysis cutoff and can select native-only independently.
