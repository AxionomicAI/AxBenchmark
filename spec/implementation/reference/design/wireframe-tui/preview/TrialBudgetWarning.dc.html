Notes

  • R3-7: there is no upper limit on trials. When a launch requests more than 5 trials for any configuration not on a local endpoint, M07’s launch validation returns trial_budget_warning with its totals.
  • Totals: task runs = configurations × trials × tasks; judge sessions = configurations × trials. The dialog states clearly that the extra trials consume budget and subscription usage.
  • Not shown when every configuration above 5 trials is on a local endpoint; local configurations are listed apart as using no budget.
  • Focus starts on Back to review. run --no-tui prints the same warning and continues; it never prompts (M14).
  • Implementation owner M07. API seam: configs.review totals/token → fresh confirmation → runs.launch; never a local budget calculation.
  • Unrendered lifecycle/interaction acceptance cases are mapped in ownership-ledger.md; this static board is not a Textual runtime test.
