Notes

  • Snapshots per request of the main agent: w1 reaches 251.3k (92%), a native auto-compaction opens w2 with a 2.4k summary, and w1 stays retained with its 24 snapshots.
  • Three scopes are never summed: current input of r31, the observed stream since T5 started, and cumulative billed input (612.4k, cached 498.0k). Only the first has a percentage.
  • Subagents have their own windows (sub · tests w3; sub · lint w4 not exposed) and are never pooled into a synthetic current context.
  • Implementation owner M10. API seam: measurements.context.sessions/snapshot/history/segments/analysis with ContextTarget + AnalysisSelection; measurements.context.reclassify job only on explicit confirmation; snapshot/analysis.updated/gap events; capability can_reclassify.
  • Unrendered lifecycle/interaction acceptance cases are mapped in ownership-ledger.md; this static board is not a Textual runtime test.
