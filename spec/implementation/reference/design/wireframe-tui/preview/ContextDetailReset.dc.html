Notes

  • T6: a native reset ends w3 (nothing carried over), then the harness drops 18 old messages and w5 starts; each transition keeps previous/new window IDs and every earlier snapshot.
  • A spool-full capture gap (21:51:02–09) is typed with its range: r16 and r17 are missing, shown as ⚠, never zero and never interpolated.
  • Windows are never added together; billed input over the task is a separate scope.
  • Implementation owner M10. API seam: measurements.context.sessions/snapshot/history/segments/analysis with ContextTarget + AnalysisSelection; measurements.context.reclassify job only on explicit confirmation; snapshot/analysis.updated/gap events; capability can_reclassify.
  • Unrendered lifecycle/interaction acceptance cases are mapped in ownership-ledger.md; this static board is not a Textual runtime test.
