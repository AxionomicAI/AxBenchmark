Output contract

stdoutresults and progress, one line per event · no colour needed
stderrproblems, one per line, prefixed ✗
glyphs✓ ✗ ▲ ● ○ ? as in the TUI, always with words
TTYrun never prompts; a missing choice is an error · only doctor --verify reads stdin: [y/N] on a terminal, --yes otherwise (no terminal and no --yes: exit 2)
exit0 success (a completed run, even with failed tasks or a failed report) · 1 typed error · 2 usage · 3 engine unreachable or incompatible
--jsonstatus RUN_ID --json is the machine-readable state; scripts read task failures there
