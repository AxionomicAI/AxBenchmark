AxBenchmark · benchmark AI coding harnesses on approved templates. Without a command it opens the terminal UI.
Usage
Command Does
axbenchmark open the TUI · library, setup, readiness
axbenchmark --attach RUN_REF observe a running run · never restarts tasks
axbenchmark run --config benchmark.yaml --no-tui validate, freeze, run unattended · plain output
axbenchmark status RUN_REF saved status and failures · no TUI needed
axbenchmark stop RUN_REF stop and clean up processes and services
axbenchmark models refresh discover models · keeps the last valid catalog
axbenchmark doctor check prerequisites · actionable guidance
axbenchmark report RUN_DIR regenerate the offline report · no model calls
axbenchmark templates export TEMPLATE_SHA --output template.zip export one exact revision
axbenchmark templates import template.zip validate, recompute SHA-256, then add
axbenchmark results export RUN_REF --output results.zip records, evidence, provenance and the template
axbenchmark results import results.zip --template TEMPLATE_SHA validate identities and digests, then add
Options for run
--jobs N configurations at once · default: one per harness, up to 4 · --jobs 1 runs them one at a time
--no-tui plain progress, never asks · waits for the completion report and prints its path
--no-wait-report exit after the outcome · the report is still written · prints the regeneration command
--config FILE a complete configuration: template SHA-256, entries, policy, judge, both weight sets
Options for doctor
--verify one minimal model call per harness, after a [y/N] prompt listing them · nothing is called on No
--yes consent without a prompt · required when there is no terminal (otherwise exit 2)
Exit codes
0 success · includes a run that completed with failed or unverified tasks (see status --json)
1 typed error · rejected package, not found, incomplete config, followed run stopped/interrupted
2 usage · unknown command, option or argument · doctor --verify without a terminal and without --yes
3 engine unreachable or incompatible · nothing was started or changed
Every command uses the same validation and lifecycle as the TUI. Closing a terminal never stops a run.
